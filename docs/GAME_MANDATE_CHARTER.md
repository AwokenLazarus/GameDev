# Game Mandate Charter — Moonwake

**Status:** v1.0 — aligned with Concept Bible  
**Engine:** Godot  
**Creative source of truth:** [Moonwake Concept Bible](./MOONWAKE_CONCEPT_BIBLE.md)  
**Audience:** AI agent game studio + human creative director  

Agents must read the Concept Bible before designing or implementing systems. This charter states **non-negotiable operating locks**. Do not contradict **LOCKED** rows. Propose ADRs for gaps; do not silently invent forever-impactful systems outside pillars.

---

## 1. Mandate (one line)

Build **Moonwake**: a Godot **solo + 1–4 co-op** action roguelite—hybrid combat, Hades-like dungeon bursts into RoR2-like timed wild stages, faction boons, Ashwick hub—original **Bloodlust-adjacent** gothic frontier IP culminating in a raid on **Aurelian the Undying**.

---

## 2. Locked decisions

| ID | Lock |

| **L8** | Death → rebirth next **full moon** from moon-shadows; kill Aurelian → **NG+** (heat + new generals) |
| **L9** | Meta: **Blood / Ash / Tech** currencies; Ashwick rebuild unlocks vendors/missions; RoR2-style character + alt-kit unlocks + skins |

---

## 3. Design pillars

1. **Escalating hunt power** — expressive late builds, not empty numbers  
2. **Readable skill under chaos** — auto layers never excuse unfairness  
3. **Burst → expanse rhythm** — dungeons then wild stages  
4. **Death continues the story** — moon curse, hub, unlocks  
5. **Gothic frontier atmosphere** — dust, moonlight, chromegoth, loneliness  
6. **Together or alone** — co-op is first-class and shared-alignment clean  

---

## 4. Anti-pillars

- Not a VHD/Bloodlust clone (no protected names, likenesses, plot lifts)  
- Not pure AFK auto-survivor for all kits  
- Not room-only Hades slog without wild stages  
- Not RoR2 item-stack fantasy (boons instead)  
- Not Tears of Metal army layer  
- Not live-service FOMO / cozy whimsy / purple-default AI look  
- Not persistent gear treadmill as meta  

---

## 5. Reference hierarchy

## 6. Agent rules

1. Read Concept Bible + this charter before work  
2. Never violate L1–L12 or hard IP bans  
3. Prefer inventing inside pillars over scope expansion  
4. Co-op + solo implications on every combat/economy change  
5. Remnant ancestries = Paleleaf / Hollowkiln / Cinderborn / Saffron Host (etc.), not trademarked D&D race labels in fiction  
6. Open polish items in Concept Bible §15 may be proposed by agents; promote to locked only with human OK or explicit “agent decides”
